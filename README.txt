CHADAO — головна сторінка

Файли:
- index.html — головна сторінка
- assets/css/style.css — стилі та адаптив
- assets/js/script.js — мобільне меню та анімації
- assets/images/ — локальні зображення

Запуск:
Відкрийте index.html у браузері.
Для локального сервера можна виконати в папці проєкту:
python3 -m http.server 8000
і відкрити http://localhost:8000

Примітка:
Посилання на сторінки Чай / Посуд / Подарункові набори зараз ведуть до секцій головної.
Окремі сторінки будуть підключені на наступному етапі.
Контакти та посилання на соцмережі зараз демонстраційні — їх легко замінити у index.html.
